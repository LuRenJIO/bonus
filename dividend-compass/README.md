# 拾息记 —— 低波红利策略微信小程序

面向低波红利策略的 A 股研究工具：输入股票名称 / 拼音 / 代码，自动获取实时行情、历年财报与分红记录，计算 TTM 股息率，并用三种模型（分红趋势 / 派息率×净利 / 机构一致预期）预测下一分红年度的预期分红与预期股息率，附分红可持续性体检。

> 数据来源：东方财富（财报 F10 / 分红送配）、腾讯财经（实时行情 / 搜索）、新浪财经（行情备用）。
> 仅供个人研究参考，不构成投资建议。

## 一、功能总览

| 功能 | 说明 |
|---|---|
| 股票搜索 | 支持中文名称 / 拼音首字母 / 6位代码（沪深A股，科创板创业板已覆盖，北交所暂不支持） |
| 实时行情 | 最新价、涨跌幅、换手、PE(TTM)、PB、市值等，三级数据源自动回退 |
| TTM 股息率 | 近 12 个月已实施税前分红合计 ÷ 最新股价（对中期+年末多次分红的公司最准确） |
| 年度分红视图 | 历年每股分红、分红次数、派息率（分红总额÷归母净利润）、按现价计股息率 |
| 预测·多模型区间 | 模型A 分红趋势外推（CAGR 限幅）+ 模型B 均值派息率×预测净利润 + 模型C 机构一致预期EPS×派息率，输出保守/中性/乐观三档 |
| 预测·盈利修正 | 在多模型基础上叠加：最新报告期增速动量、盈利稳定性、现金流覆盖、分红连续性、机构一致预期、行业与机构态度六大修正因子 + 信心度评分 |
| 股息率阶梯·买入参考价 | 按预期分红（盈利修正中性）反推 3%~9% 每 0.5% 一档共 13 档对应股价，高亮最接近现价的一档 |
| 股息率曲线 | 近 5 年月末 TTM 股息率（不复权月末收盘价 ÷ 近 365 天已实施分红，与核心口径一致）金色曲线 + Canvas 绘制，末尾红色虚线延伸至预期股息率点 |
| 股息率历史分位 | 当前 TTM 股息率在近 5 年 66 个月中的分位（≥70% 股息率高位·相对低估 / ≤30% 相对偏贵），红利策略择时核心指标 |
| 波动与风险 | 近 1 年年化波动率（月度收益 ×√12）、近 1 年最大回撤、近 5 年 Beta（对沪深300，月度）——补齐"低波"因子 |
| 分红日历 | 自选股近 90 天分红安排（含预案）+ 全市场未来 30 天除权除息日程（按日分组，仅现金分红） |
| 收息记账 | 录入持仓（股数/成本），自动统计今年已收分红（税前）、组合 TTM 股息率、持仓市值与盈亏、预期年度分红现金流，云数据库多端同步 |
| 分红可持续性体检 | 6 维度打分（派息率、连续性、盈利稳定性、现金流、未分配利润、负债），输出 0-100 分与等级 |
| 自选股 | 云数据库存储，多设备同步（同一微信账号） |
| 最近浏览 | 本地存储，最多 10 条 |

## 三、部署步骤（首次）

### 1. 注册小程序账号并获取 AppID

1. 访问 [mp.weixin.qq.com](https://mp.weixin.qq.com/) → 立即注册 → **小程序**
2. 主体类型选 **个人**（免费，需邮箱 + 身份证）
3. 注册完成后：设置 → 基本设置 → 账号信息 → **AppID**

### 2. 导入项目

1. 下载安装 [微信开发者工具](https://developers.weixin.qq.com/miniprogram/dev/devtools/download.html)（稳定版）
2. 打开开发者工具 → 导入项目 → 选择本目录 `dividend-compass`
3. AppID 已预填在 `project.config.json` 中（`wx10aac5465d7fd67d`），导入时确认显示一致即可

### 3. 开通云开发（必须）

1. 开发者工具顶部点击 **「云开发」** 按钮 → 开通
2. 创建环境（名称任意，如 `prod`），选择 **按量付费** 基础套餐（个人研究用量很小）
3. 记住环境 ID（如果只创建了一个环境，代码无需任何修改）

> 云开发是必须的：小程序前端受微信域名白名单限制，无法直接调用东方财富/腾讯接口，所有外部数据请求由云函数中转。云开发云函数不受白名单限制。

### 4. 部署云函数（关键步骤）

在开发者工具左侧文件树中：

1. 右键 `cloudfunctions/stock-service` → **上传并部署：云端安装依赖**
   - 该函数零外部依赖，部署很快
   - ⚠️ 部署后必须调超时：打开 [云开发控制台](https://tcb.cloud.tencent.com/) → 云函数 → `stock-service` → 函数配置 → **编辑 → 超时时间改为 20 秒**（默认 3 秒会因抓取外部数据超时）
2. 右键 `cloudfunctions/favorites` → **上传并部署：云端安装依赖**（需要安装 wx-server-sdk）
   - `favorites` 超时保持默认即可；首次调用会自动创建 `favorites` / `holdings` 数据库集合，无需手动建

> 本次更新（分红日历 / 收息记账 / 分位与风险指标）涉及**两个云函数都有改动**，已部署过的用户需重新上传这两个函数。

### 5. 运行

- 开发者工具点击「编译」，模拟器中即可使用
- 手机预览：工具栏「预览」扫码，或「真机调试」

## 四、核心口径与算法说明

### TTM 股息率（主口径）

```
TTM股息率 = 近365天内已实施除息的每股税前现金分红合计 ÷ 最新股价
```

- 采用**实施日**口径（除息日落在近 12 个月内），已剔除仅预案/未实施的分红
- 税前口径（含税）
- 对"中期分红 + 年末分红"的公司（如贵州茅台）能准确反映真实现金回报

### 年度归属

年度分红按 **报告期归属年** 聚合：2025-09-30 的三季度特别分红与 2025-12-31 的年度分红都计入 2025 年度，与上市公司"年度利润分配"语义一致。

### 预测·多模型区间（模式一）

- **模型A 分红趋势外推**：最近 3~5 个分红年度每股分红的复合增速（CAGR，限幅 ±30%）外推下一期
- **模型B 派息率 × 预测净利润**：近 3 年平均派息率（限幅 5%~150%）× 预测净利润（近 2~3 年净利 CAGR 限幅 ±50%）÷ 总股本
- **模型C 机构一致预期**：近 1 年券商研报一致预期 EPS（中位数，已综合最新业绩、财报与行业景气）× 均值派息率；无研报覆盖时自动缺失
- 区间：保守 = min(有效模型)×0.9，中性 = mean(有效模型)，乐观 = max(有效模型)×1.08；单模型有效时按 ±10%~15% 展开

### 预测·盈利修正（模式二）

在多模型区间基础上叠加修正因子（乘数调整）：

| 因子 | 逻辑 |
|---|---|
| 最新业绩动量 | 最新报告期净利同比增速与 3 年趋势按 6:4 加权，修正年度盈利预期 |
| 盈利稳定性 | 近 3 期净利增速标准差越大，预测越保守（0.75~1 乘数） |
| 现金流覆盖 | 近 3 年经营现金流/净利润 <1 时下调（0.7~1 乘数） |
| 分红连续性 | 连续 ≥8 年 ×1.05，5-7 年 ×1.0，3-4 年 ×0.95，<3 年 ×0.88 |
| 机构一致预期 | 一致预期 EPS 相对趋势外推隐含 EPS 的偏离（限幅 ±25%）修正盈利预期 |
| 行业与机构态度 | 所属行业 + 近 1 年研报评级分布：正面占比 ≥80% ×1.03，出现负面评级 ×0.90~0.96 |

并输出 0-100 信心度评分（分红历史长度、连续性、稳定性、现金流、派息率稳定性、机构覆盖充分性与预期一致性综合）。

> 数据缓存说明：overview 云函数内存缓存 5 分钟；详情页右下角「刷新」按钮与下拉刷新会带 `refresh=true` 绕过缓存强制拉取最新行情。

### 分红可持续性体检（6 维度加权）

派息率水平(22%) + 分红连续性(20%) + 盈利稳定性(18%) + 现金流质量(15%) + 未分配利润覆盖(15%) + 负债水平(10%) → 0-100 分与 A/B/C/D 等级。

## 五、常见问题

| 问题 | 处理 |
|---|---|
| 详情页提示"加载失败：行情获取失败" | 三个行情源同时不可用（概率极低），下拉重试 |
| 详情页提示"云函数不存在" | stock-service 未部署，或部署的环境与 `wx.cloud.init` 环境不一致 |
| 详情页报 -404011 / -501000 等 | 云函数未部署或超时时间未改到 20 秒 |
| 自选区提示"云端自选暂不可用" | favorites 未部署，或云开发未开通 |
| 搜索无结果 | 仅支持沪深 A 股；北交所 / 港股 / 美股为后续版本规划 |
| 行情/分红数据为空 | 次新股或刚上市公司历史数据不足属正常现象 |
| 分红记录含"10转X"等送转 | 送转不影响现金分红计算；历史每股分红未做复权处理（按当时股本口径） |
